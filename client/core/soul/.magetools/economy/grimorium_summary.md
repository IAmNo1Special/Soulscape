# Domains
Economy, Marketplace Operations, Inventory Management, Trade

# Summary
This suite of tools provides a complete interface for agents to engage with a digital marketplace system. It encompasses functionalities for listing items for sale, searching for available goods, executing purchases using a specified currency, and managing active sale listings. The system facilitates the exchange of items between agents and includes mechanisms for price setting, search filtering, and transaction finalization with integrated tax handling.

# Major Capabilities
-   **List Items for Sale**: Agents can place items from their personal inventory onto a global marketplace, specifying an Essence price. The item is then held by the marketplace until a transaction occurs or the listing is cancelled.
-   **Browse Marketplace Listings**: Agents can query the global marketplace to discover available items, with options to filter results by item name partial match or a maximum Essence price.
-   **Purchase Items**: Agents can acquire items from active marketplace listings by expending Essence. This action instantaneously transfers the item to the buyer's inventory and compensates the seller, deducting a marketplace tax.
-   **Cancel Sale Listings**: Agents can remove their own active listings from the marketplace, retrieving the unsold item back into their personal inventory.
